# 功能模块名称

## 目标与非目标

说明模块解决的问题、用户或系统价值，以及明确不负责的内容。

## 模块边界与所有权

说明负责的 package、feature 或团队，以及 App、SDK、后端、设备和存储等相邻系统的职责边界。

## 入口与目录结构

列出页面、Provider、UseCase、Repository、Gateway、公共 API 或其他关键入口及其源码位置。

## 核心流程

说明主成功路径、关键分支和重要状态转换；关系复杂时使用最小必要的流程图或状态图。

## 数据与状态

说明数据来源、权威状态、缓存、持久化、同步、失效和一致性边界。

## 外部契约

说明公共 API、SDK、后端接口、schema、设备协议和兼容性要求。

## 生命周期与错误恢复

说明初始化、暂停、恢复、切换、解绑、重试、异常、降级和回滚行为。

## 验证

列出长期维护的核心测试入口、人工验收、真机或外部门禁；不要复制一次变更的完整命令日志。

## 已知限制

记录当前未支持的场景、外部依赖、Owner 边界和仍需独立验证的结果。
